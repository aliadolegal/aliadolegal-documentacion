# AliadoLegal

**AliadoLegal** es una plataforma digital de tecnología jurídica (LegalTech) desarrollada en México para facilitar el acceso a servicios jurídicos, relacionando los problemas legales de las personas con la experiencia profesional de abogados mediante inteligencia artificial, procesamiento semántico y conceptos jurídicos.
